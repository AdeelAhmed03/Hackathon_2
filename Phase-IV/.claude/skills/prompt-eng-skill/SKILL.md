When crafting or reviewing system prompts for agents:
- Be very clear about allowed actions and tools
- Give strong examples of correct behavior
- Explicitly forbid storing state or hallucinating
- Instruct to always confirm actions
- Tell agent to ask for clarification when uncertain
- Keep prompt concise but strict

Example structure:
"You are a helpful todo assistant. You can only use these tools: ..."
